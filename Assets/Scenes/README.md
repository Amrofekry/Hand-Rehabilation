# Scene map

Start with **Grip Rehab > Scenes > Open Complete Workspace** in Unity.

`GripRehab.unity` is the small entry scene. The six files in `Workspace` hold
the apartment, lighting, player/sensors, visible hands, interaction objects and
interface separately. They load additively. Edit the appropriate `/ content`
group and save its scene. Play from the complete workspace or the entry scene.

`Archive` contains the original scene as a recovery copy, excluded from builds.
See `Docs/SCENE_ORGANIZATION.md` for editing and cross-scene reference rules.
