# Hand Landmarker model

`hand_landmarker.task` is the official MediaPipe HandLandmarker (full, float16) model bundle downloaded from [Google's model page](https://developers.google.com/edge/mediapipe/solutions/vision/hand_landmarker/index) on 2026-09-23. Source URL: `https://storage.googleapis.com/mediapipe-models/hand_landmarker/hand_landmarker/float16/latest/hand_landmarker.task`.

SHA-256: `FBC2A30080C3C557093B5DDFC334698132EB341044CCEE322CCF8BCF3607CDE1`.

The [Google model card](https://storage.googleapis.com/mediapipe-assets/Model%20Card%20Hand%20Tracking%20(Lite_Full)%20with%20Fairness%20Oct%202021.pdf) states Apache License 2.0; a copy is included in `LICENSE-2.0.txt`. The model card describes experimental research/entertainment use and limitations under occlusion and gloves. It is not a medical-device validation.
