## 3. Why the folder is 40 GB (measured 2026-11-23)
The game itself (`Assets`) is 0.18 GB. Almost everything else is old releases, logs and spare Python environments:

| Folder | Size | What it is | Action |
|---|---|---|---|
| `.local/release` | 10.4 GB | 10 versions (1.0.0-1.0.8, 1.2.0), each a 248 MB zip and a 178 MB installer | Keep 1.2.0 and the demo video; delete the rest (about 9.5 GB) |
| `Logs` | 9.1 GB | Test outputs, regenerated by every run | Delete all but the real Hand Lab recordings |
| `.local/cache` | 5.6 GB | Python/npm/Unity package caches | Prune unused uv entries, delete pip and npm caches (the MCP tools run from the uv cache: never wiped) |
| `.venv-cv` | 4.7 GB | Environment of the YOLO tracker, which is not used | Delete |
| `ai-engine` | 3.3 GB | 1.5 GB current environment (needed) and 1.7 GB old one | Delete `.venv-ai-old` |
| `.local/scratch` | 2.3 GB | Scratch files | Delete |
| `Library` | 1.9 GB | Unity's cache | Keep (deleting forces a long re-import) |
| `.git` | 1.2 GB | History: 532 MB packed (done 2026-11-23, nothing lost) and 624 MB of large-file (LFS) copies | `git lfs prune` drops old copies |
| `firmware` | 1.0 GB | Arduino toolchains | Delete (re-downloaded by `firmware/setup.ps1`) |
| `CVTraining` | 0.6 GB | YOLO datasets and runs | Delete (the small weights stay) |

All of it is in one script. Run it with Unity and the game closed (the assistant is not allowed to run mass deletes):

```
powershell -ExecutionPolicy Bypass -File E:\GP\codex\GripRehab-Unity\Tools\release\Cleanup-Project.ps1
```

Expected result: about 7-9 GB (it prints the size before and after).

## 5. Problems found and fixed in this review
- **Unity console warnings:** "Setting linear/angular velocity of a kinematic body" when an activity rested or snapped an item. Fixed in `ActivityRunner.cs`, and `Tools/test_kinematic_velocity.py` fails on any unguarded velocity write.
- **Cleanup script:** it now also removes the generated graph (`graphify-out`), the old MCP backup, and the pip and npm caches. It prunes unused uv cache entries and old LFS copies.
- **Git history:** packed (6,388 loose files into one pack). No commit was lost.
